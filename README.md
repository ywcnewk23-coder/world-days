# World Days｜世界の記念日カレンダー

iPhone・iPadを含むブラウザで使える、日本語のレスポンシブなウェブアプリです。静的サイトとして公開でき、URLを友達と共有できます。

## 機能
- 月間カレンダー（前月・翌月・今月へ移動）
- 記念日のある日をカレンダー上で表示
- 日付を選んでその日の記念日を一覧表示
- 国別一覧と国名・記念日・由来の検索
- 記念日の詳細、関連年、由来、参照リンク
- PWA用マニフェストと簡易オフラインキャッシュ

## 公開方法（無料の静的ホスティング例：GitHub Pages）
1. GitHubで新しいリポジトリを作成します（例 `world-days-calendar`）。
2. このZIPを解凍し、中にあるファイルをすべてリポジトリの最上位にアップロードします。
3. リポジトリの **Settings → Pages** を開き、Build and deployment を `Deploy from a branch`、Branch を `main` / `/(root)` に設定して保存します。
4. 公開完了後に表示されるURL（通常 `https://ユーザー名.github.io/world-days-calendar/`）を友達に共有します。
5. iPhone/iPadではSafariでURLを開き、共有ボタン → **ホーム画面に追加** を選ぶとアプリアイコンから起動できます。iOSのバージョンによって表示が異なる場合があります。

GitHub Pagesの公式案内: https://docs.github.com/pages

## データを追加・編集する
`data.js` の `window.WORLD_DAYS` 配列に記念日を追加します。各項目は以下の形式です。

```js
{
  id: "unique-id",
  country: "国名（日本語）",
  countryEn: "Country name",
  flag: "🏳️",
  date: "MM-DD",
  name: "記念日の名称",
  type: "独立記念日",
  year: 1900,
  description: "由来や意味",
  note: "補足（任意）",
  sources: [{ label: "出典名", url: "https://example.org/" }]
}
```

同じ国に複数の記念日を登録できます。`year` は不明または該当しない場合 `null` にします。閏日（02-29）もデータとして登録できます。

## 公開前に必ず確認すること
- このパッケージの収録データは初期サンプルであり、全世界の全記念日を網羅したものではありません。
- `sources` のURLは調査の起点として提供しています。各URLが個々の記念日の日付・説明を直接裏付けるとは限らないため、公開前に公式政府機関などの一次資料で確認してください。
- 国の「建国日」「独立日」「国民の日」「憲法記念日」などは意味が異なります。歴史的な出来事と現行の祝日を混同しないようにします。
- 一部の記念日は歴史的・政治的に複数の解釈があります。説明では文脈を省略せず、断定しすぎないようにします。
- 外部のGoogle Fontsが読み込めない場合も、端末の標準フォントで表示されます。

## 通知について
この初期版では端末通知を実装していません。毎日アプリを開いて使うカレンダーとして動作します。後日通知を追加する場合、iOSのウェブ通知の対応条件や許可操作、プッシュ配信のためのサーバーなどを別途実装・検証する必要があります。
